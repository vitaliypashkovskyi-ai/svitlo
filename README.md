# Світло Київ

Онлайн-графік планових відключень світла ДТЕК Київські електромережі за чергами: 24-годинний циферблат для вашої черги, відлік до наступного ввімкнення чи відключення та всі 60 черг зараз. Українська та англійська.

Live outage schedule for DTEK Kyiv Electric Networks queues, in Ukrainian and English.

**Сайт:** https://vitaliypashkovskyi-ai.github.io/svitlo/

## Регіони

м. Київ (60 черг), Київська, Дніпропетровська та Одеська області (по 12 черг) — мережі ДТЕК, для яких є дані. Пошук за адресою: Київ і Дніпропетровська область (спершу населений пункт). Посилання на чергу: `#q4-1` (Київ), `#dnipro-q1-2`, `#odesa-q3-2`, `#kyiv-region-q2-1`.

## Звідки дані

- Графік: публічна копія даних ДТЕК [Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua), оновлюється приблизно кожні 5 хвилин. Сторінка завантажує її сама раз на 5 хвилин.
- Пошук черги за адресою: API YASNO. Браузер не може звертатися до нього напряму, тому потрібен проксі: `api.php` (наприклад, на QNAP Web Server) або `server.py` локально. На GitHub Pages пошуку за адресою немає, замість нього посилання на сайт ДТЕК.

Це неофіційний сайт. Аварійні відключення тут не відображаються — перевіряйте офіційний сайт ДТЕК.

## Telegram-бот

`bot/bot.py` — бот: пошук черги за адресою, графік на сьогодні й завтра, нагадування за 30 хвилин до відключення та коли опублікують графік на завтра. Лише стандартна бібліотека Python. Токен від @BotFather кладеться в `bot/.env` (див. `bot/.env.example`); `bot/docker-compose.yml` — для QNAP Container Station. Перевірка без Telegram: `python bot/bot.py --test "Хрещатик" 22`.

## Файли

- `index.html` — увесь сайт (HTML, CSS, JS в одному файлі).
- `api.php` — проксі для пошуку за адресою на хостингу з PHP.
- `server.py` — локальний сервер із тим самим проксі: `python server.py`, потім http://127.0.0.1:8777
